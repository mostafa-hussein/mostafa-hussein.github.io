Multimodal Object Identification at Warehouse Scale

The perception model behind Amazon's Sparrow picking robot.

Amazon Robotics · 2022 – 2024 · Applied Scientist II

A picking robot in a fulfillment center has to recognize which item it is holding, out of an open-ended catalog of products. The reference images for an item are often incomplete, and items arrive occluded, deformed, or in changed packaging.

I developed a multimodal object-identification model that matches a camera crop against several partial reference sources at once: photos taken during fulfillment, the catalog image, and the catalog title text. A DINO vision transformer gives domain-invariant image embeddings, catalog titles are aligned to the same space with CLIP-style contrastive fine-tuning, and a gradient-boosted model fuses the per-source matches while tolerating missing sources.

Matching object segments in a bin against multiple partial reference sources.

On ARMBench (190K+ objects) extended with these reference sources, the fused model identified 92–97% of objects across reference-coverage scenarios, holding up where nearest-neighbor matching lost precision. In production it shipped to Sparrow stations across U.S. fulfillment centers and raised identification accuracy from about 80% to 98.5%.

Published at ICRA 2024 (Mitash et al., 2024).

Tools: vision transformers · DINO · CLIP · contrastive learning · multimodal retrieval

    Scaling Object-centric Robotic Manipulation with Multimodal Object Identification
    Chaitanya Mitash, Mostafa Hussein, Jeroen Vanbaar, Vikedo Terhuja, and Kapil D. Katyal
    In 2024 IEEE International Conference on Robotics and Automation (ICRA), May 2024
    Abs DOI Bib PDF

    Robotic manipulation is a key enabler for automation in the fulfillment logistics sector. Such robotic systems require perception and manipulation capabilities to handle a wide variety of objects. Existing systems either operate on a closed set of objects or perform object-agnostic manipulation which lacks the capability for deliberate and reliable manipulation at scale. Object identification (ID) unlocks the ability for large-scale, object-centric manipulation by mapping object segments to one of the previously seen objects from a database. Nevertheless, it is often limited by the availability of reference data or coverage for objects in a database. In this work, we propose to perform object identification with multiple reference databases, including images and text references, each with a different coverage and matching challenge. We propose a training strategy that tackles the challenges of learning domain-invariant image embeddings, image-text matching and fusing predictions from different sources. We perform experiments over a recent benchmark with over 190K+ unique objects, extend the dataset with the additional reference sources and propose an evaluation strategy that simulates coverage for different reference sources. Model trained with the proposed learning pipeline shows robust performance over a range of simulation experiments.
